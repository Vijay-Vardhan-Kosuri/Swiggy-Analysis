Project Overview:
This project analyzes Swiggy restaurant data to generate business insights and key performance indicators (KPIs). The dataset contained missing values, duplicate records, and inconsistent data that were cleaned before analysis.
Repository Contents
1. Swiggy_Analysis.ipynb
   Data cleaning
   Data exploration
   KPI generation
   Business insights and visualizations
2. Swiggy_Raw_Dataset.csv
   Original dataset containing missing values, duplicates, and inconsistent records

Tools & Technologies Used
Visual Studio Code (VS Code)
Python 3.13.3
Jupyter Notebook
Pandas
NumPy
Matplotlib
Seaborn

Project Workflow:
1. Understanding Business Requirements
Reviewed and understood the business objectives and analytical requirements.
2. Data Loading
Imported required Python libraries.
Loaded the raw Swiggy dataset into the notebook.
3. Data Exploration
Examined the dataset using:
.head()
.info()
.describe()
4. Data Cleaning
Removed duplicate records.
Handled missing values using appropriate statistical methods such as:
Mean
Median
Mode
Corrected inconsistent data where necessary.
5. KPI Generation
Calculated key business metrics.
Identified patterns and trends within the data.
6. Insight Generation
Generated actionable business insights.
Presented findings using visualizations and summary statistics.
